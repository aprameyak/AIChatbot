## About

**AIChatbot** is a modular **Next.js** chatbot component that wraps the **OpenAI** API to deliver a ChatGPT-style conversational interface. Built with **React**, **TypeScript**, and **Material UI**, it supports both OpenAI and Google Gemini backends and is designed to be dropped into any web application with minimal configuration. Authentication is handled by **Clerk**.

## Features

- Conversational chat UI backed by OpenAI GPT-4
- Secondary Gemini API integration available as an alternative backend
- Clerk authentication with email and social login support
- Stateless API route at `/api/chat` — no server-side session storage required
- Material UI component library for a polished, responsive interface
- Vercel Analytics integrated for usage tracking
- Easily embeddable as a standalone component in other Next.js apps

## Technology Stack

- **Frontend**: Next.js, React, TypeScript, Material UI (MUI)
- **Backend**: Next.js API Routes
- **AI Integration**: OpenAI API, Google Gemini API
- **Authentication**: Clerk
